# 岗位变体：市场 / 销售类（`role_family = sales`）

适用：客户经理、销售工程师、大客户销售、渠道销售、售前商务、招商。

## 一、模块顺序

1. **核心优势**（2–3 条，`bullet`）— 第一屏就要有数字
2. **教育背景** — 压到 2 行以内，学校不是卖点时不占篇幅
3. **实习经历** — 本岗位的主战场，占全篇 **50–60%**
4. **项目与实践** — 只留能证明"能落地/能开拓"的
5. **荣誉 · 技能 · 实践** — 合并成一个模块，压到 3 条以内

## 二、销售岗到底在筛什么

面试官 10 秒内扫四件事：**有没有卖过东西的数字 → 有没有对接过"组织" → 地点/异地意愿 → 时间线是否连续**。
所以每条要点都要回答其中一个，回答不了的删掉。

「卖过东西的数字」按优先级取：成交额 > 回款 > 签约单数 > 意向线索数 > 拜访量 / 外呼量 > 客户池规模。
只有体量没有成交时，**不要含糊其辞，直接把链路写清楚**：触达 → 邀约 → 到场 → 回访。

## 三、语言风格

- 用客户侧动词：`走访 / 外呼 / 邀约 / 测算 / 报价 / 谈判 / 回款 / 复购`，不用 `参与 / 协助 / 配合`。
- 把"做了什么"翻译成"客户因此做了什么决定"：
  - 差：`负责商户的租金测算`
  - 好：`把租金拆成「每天每平米多少成本」，用数字支撑报价与谈判`
- 客户分类要显性：`按业态 / 面积 / 预算分层，排定拜访优先级`。
- 异地意愿按事实强弱分档，别一律写"接受长期驻外"：
  - 事实只写"接受其他城市" → `工作地点：接受全国调配（意向 武汉 / 广州 / 深圳）`
  - 事实明确写"可长期驻外 / 高频出差" → 才可以写 `接受全国调配（意向 华东 / 华中 / 华南）`
  - 事实写"仅接受某市" → 如实写，并在 `gaps` 里提示这不匹配岗位的调配要求

## 五、配比与禁忌

- 实习占 50–60%，核心优势 15%，其余合计 ≤30%。
- 禁忌：只写"沟通能力强 / 抗压"；把行政、文案类兼职当主经历；写了客户数却没有转化链路；地点写成"只想留在某市"。
- 有驾照、学生会外联拉赞助、体育特长，**优先塞进"荣誉 · 技能 · 实践"**——销售岗看这些，研发岗不看。
