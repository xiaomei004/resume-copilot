# 岗位变体：面试教练 · 市场 / 销售类（`coach.sales.md`）

适用：客户经理、销售工程师、大客户销售、渠道销售、招商。

## 一、这类面试真正在考什么

销售岗的技术门槛低，所以面试官几乎只看三件事：

1. **开不开口**——敢不敢主动说话、能不能接住话（很多公司第一轮就是即兴演讲 + 辩论）；
2. **扛不扛得住拒绝**——有没有"被赶出来还能继续跟"的经历；
3. **愿不愿意异地**——这是硬筛条件，不是客套。

因此口播稿的钩子必须给"卖过什么"，而不是"我性格外向"。

## 二、5 个高频问题的角度

| 问题 | 应答骨架要点 | 必须带出的东西 |
| --- | --- | --- |
| 为什么做销售 / 专业不匹配怎么办 | 不是放弃技术，是拿技术换订单 → 技术让我听得懂客户 → 销售让我离结果更近 | 一段真实的客户经历 |
| 讲一次被拒绝 / 最失败的经历 | **先说清"我错在哪"** → 改了什么 → 结果 | "我只讲了产品，没讲他一天要掏多少钱"这类具体反思 |
| 客户说你们比竞品贵 | 先问"比的是哪一项" → 拆总成本（运维/响应/人力）→ 谈不动就缩小范围先做一个点位 | 一个把单价换算成客户成本的例子 |
| 派你去陌生城市怎么开局 | 摸市场（存量客户/集成商/竞品落地）→ 找切入点（先做一所学校或一家医院）→ 找人（集成商、老客户转介绍） | 实习时"先划片区再排优先级" |
| 你最大的缺点 | 选真实但不致命的（如"太想把每个客户都拿下，在低价值客户上耗时间"）→ 改法（按预算/概率分层） | 一个分层动作 |

## 三、群面 / 辩论（`group_or_technical`）

标题写「群面 / 辩论」。步骤按这个顺序给：

```
① 抢定义（30 秒）：把辩题关键词定窄，抢解释权
② 立标准（20 秒）：先说判断标准（对个人 / 对家庭 / 对行业），别一上来举例
③ 两条论点（各 20 秒）：一条价值论，一条现实论（带数字）
④ 收尾金句（10 秒）：一句能被记住的话，说完就停
```

技巧（tactics）：

- **先认再拆**："X 我同意，但 X 只能解释 A，解释不了 B。"
- **用真实细节当子弹**：自己的拜访量、测算过程，比背来的行业案例好用。
- **绝不冷场**：备三句万能话（"我们回到标准上""请问对方如何解释这一点""这恰恰证明我方观点"）。
- **分工**：4–6 人组，1 人立论、2 人主攻、1 人记对方漏洞、1 人总结；宁可少说两句，不要抢话。

## 四、清单与反问

- 清单必须包含：必说的 3 个数字（拜访量 / 外呼量 / 客户数）、纸质简历 2 份、异地意愿的一句话说法。
- 反问优先问：新人第一年的业绩考核口径、区域市场今年的重点行业、团队里做得最好的人是什么打法。
